Hệ thống

Kiến trúc đang vận hành
· Website tĩnh phát hành qua GitHub Pages, tên miền www.kk-mall.com (HTTPS bắt buộc).
· Bộ thu thập đám mây chạy 3 giờ/lần, 24/7 (GitHub Actions) - cập nhật giá, tồn kho, sổ cái giá hash-chain và tự làm mới gói dữ liệu quản trị mã hóa của trang này.
· Hệ số định giá nội bộ và khóa quản trị nằm trong GitHub Secrets (PRICING_OFFSET, ADMIN_PORTAL_KEY) - không có trong mã nguồn hay dữ liệu công khai.
· Sổ cái giá công khai để khách tự kiểm chứng: api/ledger-verify.json (chỉ chứa giá KK, không chứa nguồn).
· Mã nguồn đầy đủ (máy chủ động Node.js: đơn hàng thật, thanh toán, hóa đơn, điều phối, Passkey...) lưu tại OneDrive + Google Drive của chủ sở hữu.

Đổi khóa quản trị: cập nhật Secret ADMIN_PORTAL_KEY trong GitHub → chạy lại workflow "Thu thập dữ liệu" → khóa cũ hết hiệu lực ngay lần phát hành sau.
